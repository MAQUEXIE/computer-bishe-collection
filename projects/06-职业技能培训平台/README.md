# 06 职业技能培训平台

课程售卖、视频学习进度、作业批改、课时与证书的机构化培训 SaaS。
技术栈：**FastAPI + SQLAlchemy 2.0 + PyMySQL + Pydantic**（后端）· **Vue3 + Vite + Element Plus + Pinia**（前端）。

> 说明：清单文档中提到的 Tortoise-ORM 已按统一规范替换为 SQLAlchemy 2.0（Python 3.13 兼容）。

---

## 系统功能

### 1. 管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **课程管理**：审核发布课程
- **讲师管理**：管理讲师账号
- **学员管理**：管理所有学员
- **订单管理**：查看缴费订单
- **分类管理**：课程分类
- **证书管理**：审核颁发证书
- **数据统计**：平台运营数据

### 2. 讲师

登录、个人信息、修改密码。

- **课程管理**：上传课程视频
- **章节管理**：编辑课程章节
- **作业管理**：布置批改作业
- **学员管理**：查看学员列表
- **数据统计**：课程学习数据

### 3. 学员

注册、登录、个人信息、修改密码、查看系统公告。

- **课程浏览**：浏览所有培训课程
- **报名缴费**：报名课程支付
- **在线学习**：看视频学习
- **学习进度**：查看学习进度
- **提交作业**：完成作业提交
- **考试测评**：课程结束考试
- **证书查询**：查看获得证书

## 四、功能与创新点

### 学员
- 课程商城浏览 / 搜索 / 分类，立即购买下单（模拟支付，自动生成订单+机构分成收益流水）
- **视频学习与进度**：章节目录按节学习，"播放视频(模拟)"与"标记学完"记录每章观看百分比（0-100），跨次登录续看；课程总进度自动汇总
- 作业提交：带作业的章节可提交作业，等待讲师批改
- **结课证书生成**：学完全部章节(100%)且作业全部及格后可申请证书；证书页可查看，一键下载 PNG 图片（Canvas 绘制，含印章）

### 讲师
- 创建课程（草稿）→ 发布上架
- 上传课时视频：新增章节、填写时长、选择本地视频文件、可布置作业
- 作业批改：按状态筛选，打分+评语提交
- 答疑管理：查看学员提问并解答

### 机构/管理员
- 机构入驻：机构在线申请，管理员通过/拒绝
- 学员管理：查看学员所属机构、购课数、学习章节数、证书数
- 课时统计：机构数/课程数/学员数/总课时分钟/订单数/累计收益看板 + 各机构课时明细
- 收益结算：查看各机构课程分成流水，逐笔结算

## 六、修复的 Bug（实测中发现并修复）

1. **登录后页面空白（路由组件崩溃）**：`MainLayout.vue` 中 `titles` 是普通对象却误写 `titles.value[role]`，导致 `undefined['student']` 抛错，Vue 整页白屏。修复为 `titles[role]`。

## 七、已知限制

1. **视频文件为占位**：本机无真实视频转码服务，章节视频为 `frontend/public/videos/` 下的占位文件；学习进度通过"播放(模拟)/标记学完"按钮记录，符合任务约定。
2. **鉴权为内存 token**：后端重启后登录态清空，需重新登录。
3. **密码为明文存储**：演示用，未做哈希加密。
4. **收益分成固定 80%**：机构收益=订单金额×0.8，规则写死在下单逻辑中。
5. 讲师上传视频仅记录文件名，未实际上传文件到服务器。
