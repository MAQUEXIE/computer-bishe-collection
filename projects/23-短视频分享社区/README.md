# 23 短视频分享社区

FastAPI + SQLAlchemy 2.0 + PyMySQL + Vue3 + Vite + Element Plus 的 UGC 短视频内容社区。

## 系统功能

### 1. 管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **用户管理**：管理所有用户
- **视频管理**：审核删除视频
- **评论管理**：管理评论
- **话题管理**：管理话题标签
- **举报管理**：处理举报
- **公告管理**：发布平台公告
- **数据统计**：平台运营数据

### 2. 创作者

注册、登录、个人信息、修改密码。

- **上传视频**：上传短视频
- **视频管理**：管理自己的视频
- **数据看板**：查看播放点赞数据
- **粉丝管理**：查看粉丝
- **私信**：回复私信

### 3. 普通用户

注册、登录、个人信息、修改密码、查看系统公告。

- **浏览视频**：刷视频
- **点赞评论**：点赞评论
- **关注**：关注创作者
- **私信**：发私信
- **话题**：看话题标签
- **收藏**：收藏视频
- **分享**：分享视频

## 技术栈

- 后端：FastAPI + SQLAlchemy 2.0 + PyMySQL + Pydantic（端口 **9023**）
- 前端：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios（端口 **5123**，`/api` 代理到 9023）
- 数据库：MySQL 8，库名 **db_23_short_video**（utf8mb4）

## 一键启动

```powershell
# 1. 建库建表+初始化数据（PowerShell 不支持 < 重定向，用管道）
Get-Content "db\init.sql" -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（端口 9023）
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 9023

# 3. 启动前端（端口 5123）
cd frontend
npm install
npm run dev

# 浏览器打开 http://localhost:5123
```

## 功能清单

- 用户：推荐流（关注加权+热度加权）/关注流/热门榜、搜索、视频播放、点赞取消、评论、关注取关、私信收发
- 创作者：视频发布（提交后待审核）、我的作品、数据看板（作品/播放/点赞/粉丝）、创作者收益（播放×0.001 + 点赞×0.01 折算）、收益明细、粉丝管理
- 管理员：内容审核流（通过/拒绝+审核记录）、用户管理（封禁/解封）、平台数据总览（审核流/互动/分类分布/收益发放）

## 创新点

1. **推荐流**：登录后推荐流按「关注作者作品加权置顶 + 点赞×10 + 播放」综合排序；关注流仅显示已关注创作者的作品。
2. **创作者收益**：按播放量×0.001 + 点赞数×0.01 折算收益，审核通过即生成收益记录，看板同时展示实时折算值。

## 修复的 Bug

1. **表格状态列渲染成字面量**：Publish/Dashboard/Audit/Users 四个页面的 el-tag 文本写了 `{ approved: '已通过', ... }[row.status]` 但漏写 `{{ }}` 插值，页面上原样显示 JS 对象文本。已全部改为 `{{ { ... }[row.status] }}`。
2. **浏览器自动化封禁错位**：实测用户管理时按按钮顺序点「解封/封禁」误操作了相邻行，改为按账号用户名精确定位行内按钮，最终状态恢复为 creator 正常、user3 已封禁（与种子数据一致）。
