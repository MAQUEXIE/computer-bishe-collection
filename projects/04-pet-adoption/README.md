# 宠物领养管理系统

> 基于 SpringBoot + Vue3 的宠物领养管理平台
> 
> 🔒 完整源码加微信获取

## ✨ 功能列表

### 用户端
- 浏览可领养宠物
- 宠物详情查看
- 在线申请领养
- 领养进度查询
- 养宠知识文章浏览

### 管理员端
- 宠物信息管理（增删改查）
- 领养申请审核
- 用户管理
- 文章发布
- 数据统计

## 🛠️ 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | SpringBoot 2.7 + MyBatis |
| 数据库 | MySQL 8.0 |
| 前端 | Vue3 + Element Plus |
