# 12 健身房会员管理系统

力健健身房 SaaS：卡种套餐、私教约课、体测记录、入场签到、续费预警、经营报表。

## 技术栈与端口

- 后端：SpringBoot 2.7.18 + MyBatis + MySQL 8（JDK8），端口 **9012**
- 前端：Vue3 + Vite + Element Plus + Pinia + ECharts，端口 **5112**（`/api` 代理到 9012）
- 数据库：**db_12_gym**（utf8mb4）

## 一键启动

```powershell
# 1) 导入数据库（PowerShell 管道，不支持 < 重定向）
Get-Content D:\000-计算机项目\30个系统项目\12-健身房会员管理\db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2) 启动后端（注意：必须同一条命令里切 JDK8）
cd D:\000-计算机项目\30个系统项目\12-健身房会员管理\backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'; mvn spring-boot:run

# 3) 启动前端
cd D:\000-计算机项目\30个系统项目\12-健身房会员管理\frontend
npm install; npm run dev
```

浏览器打开 http://localhost:5112

## 实测修复的 Bug

1. **ReportController 缺少 User import** → 编译失败，补充导入后重启。
2. **el-time-select 自动化点击无效**（下拉项用 JS/bu.click 都选不中）→ 会员约课与教练排课表单改为原生 `<input type="time">`，可稳定填写。
3. **后端时间序列化带 UTC 时区且前端直接显示原始 ISO 串** → application.yml 增加 `spring.jackson.time-zone: Asia/Shanghai` + date-format，前端签到列加格式化，现在显示为 `2026-10-24 17:24` 本地时间。

## 已知限制

- 登录态为前端 localStorage 保存的用户信息（无 token），后端写接口靠前端传 memberId/coachId，适合演示；生产应加 JWT + 拦截器。
- 续费在同卡种不限次卡上自动在原到期日后续延，次卡续费按新卡记录处理。
- 密码明文存储（演示项目，未加密）。
- 浏览器自动化下 el-select 下拉（会员/教练选择框）需用 JS 触发，手工点击正常。
