# 在线考试系统

> 基于 SpringBoot + Vue3 的在线考试管理系统

## ✨ 功能列表

### 管理员端
- 用户管理（学生/教师/管理员）
- 班级管理
- 课程管理
- 题库管理（单选/多选/判断）
- 试卷管理（组卷、随机组卷）
- 考试安排
- 成绩统计与分析

### 学生端
- 在线考试（计时、自动交卷）
- 查看历史成绩
- 错题本

### 教师端
- 试题录入与管理
- 试卷批改（主观题）
- 成绩查询与导出

## 🚀 部署教程

### 环境要求
- JDK 1.8+
- Maven 3.6+
- Node.js 16+
- MySQL 8.0

### 步骤

**1. 导入数据库**
```bash
mysql -u root -p < sql/online_exam.sql
```

**2. 启动后端**
```bash
cd backend
# 修改 application.yml 中的数据库配置
mvn spring-boot:run
# 后端启动在 http://localhost:8080
```

**3. 启动前端**
```bash
cd frontend
npm install
npm run dev
# 前端启动在 http://localhost:5173
```

**4. 默认账号**
- 管理员：admin / 123456
- 教师：teacher / 123456
- 学生：student / 123456
