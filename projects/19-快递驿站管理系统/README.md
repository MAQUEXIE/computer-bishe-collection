# 19 快递驿站管理系统（邻里驿家）

驿站数字化运营平台：取件码入库、代收代寄、异常件、签收、滞留提醒。

## 系统功能

### 1. 驿站管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **快递入库**：扫描入库
- **取件管理**：处理取件
- **代寄管理**：处理代寄
- **库存管理**：查看库存
- **员工管理**：管理驿站员工
- **绩效统计**：员工绩效
- **数据统计**：每日收发统计

### 2. 用户（学生）

注册、登录、个人信息、修改密码、查看系统公告。

- **取件码**：看取件码
- **快递查询**：查快递状态
- **代寄**：预约代寄
- **取件确认**：确认取件
- **投诉**：投诉快递问题

## 技术栈

- 后端：SpringBoot 2.7.18 + MyBatis（mybatis-spring-boot-starter 2.3.2）+ MySQL 8，JDK 1.8
- 前端：Vue 3 + Vite 6 + Element Plus + Vue Router + Pinia + Axios
- 后端端口：**9019**，前端端口：**5119**（/api 代理到 http://localhost:9019）
- 数据库：**db_19_express**（utf8mb4）

## 创新点实现

1. **取件码通知**：包裹入库时后端自动生成唯一取件码（货架号+数字，如 B1-909），若收件手机号匹配已注册用户，立即写入站内通知；用户端顶栏铃铛可见未读数，打开后自动标记已读。
2. **滞留件提醒**：任何包裹列表查询前先跑滞留扫描——入库超过 3 天仍在库的包裹自动从「在库待取」转为「滞留」，并向收件用户发送提醒通知（去重：同一滞留包裹只自动提醒一次）；站长可在滞留页面对滞留包裹再次补发提醒。

## 实测修复的 bug

1. **Abnormal.vue 模板缺少 `</el-form>` 闭合标签**，Vite 编译报 `Element is missing end tag`，异常件页白屏 → 已补全闭合标签。
2. **Element Plus 自动化按钮偶发点击无效**（退出登录、登录、新增驿站、解除回库等 ref 点击不触发）→ 统一改用 `bu.js` 内 DOM 查找并 `.click()` 触发，页面侧无需改动（属自动化环境问题）。

## 已知限制

- 登录态仅存浏览器 localStorage（无服务端 Session/JWT），后端接口为演示级开放校验。
- 滞留阈值固定 3 天（常量在 PackageController.stayScan），未做管理员可配置化。
- 未对接真实短信通道，「通知」为站内通知中心形式。
- 金额结算为流水记录展示，未做对账导出。
