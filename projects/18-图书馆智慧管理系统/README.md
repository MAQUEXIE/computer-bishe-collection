# 18 图书馆智慧管理系统

图书检索、借还、逾期自动计费、荐购、座位预约、借阅热榜，馆务一体化。

## 技术栈

- 后端：SpringBoot 2.7.18 + MyBatis(注解) + MySQL 8，JDK 1.8
- 前端：Vue 3 + Vite + Element Plus + Vue Router + Pinia + Axios
- 后端端口：**9018**　前端端口：**5118**（`/api` 代理到 9018）
- 数据库：**db_18_library**（utf8mb4），连接 root/root

## 一键启动

```powershell
# 1. 初始化数据库（首次）
cd D:\000-计算机项目\30个系统项目\18-图书馆智慧管理系统
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（注意 JAVA_HOME 必须切到 JDK8）
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'; mvn spring-boot:run

# 3. 启动前端（新终端）
cd frontend
npm install   # 首次
npm run dev
```

浏览器打开 http://localhost:5118

## 创新点

1. **逾期自动计费**：`OverdueService.refresh()` 在读者查询借阅、馆员查逾期列表时自动扫描在借记录，按规则（宽限期0天、每天0.5元、单笔上限20元）实时计算逾期天数与费用；还书时按累计逾期天数结算。
2. **借阅热榜**：按 `t_borrow` 借阅记录 GROUP BY 图书统计借阅次数排行，读者首页与管理员统计报表双处展示。

## 修复的 bug（实测中发现）

1. 逾期处理/馆藏管理表格列过多，在 939px 视口下横向溢出 → 精简列（逾期处理合并"状态"为两行展示、馆藏管理去掉价格/总藏/ID 列），重截确认。
2. 浏览器自动化 `bu.click` 对 el-button 偶发不触发 → 改用 `bu.js` 直接 `.click()`（自动化环境问题，产品功能本身正常）。
3. 登录页 el-tabs 两个页签表单同存于 DOM，自动化填密码时选择器误填登录页签 → 改用 `.el-tab-pane:nth-child(2)` 精确选择（自动化操作问题，不影响真实用户）。
