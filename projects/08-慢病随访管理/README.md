# 08 慢病随访管理系统

高血压/糖尿病等慢病档案、用药提醒、随访计划、指标预警，医患协同。

## 技术栈

- 后端：SpringBoot 2.7.18 + MyBatis 2.3.2 + MySQL 8（JDK8）
- 前端：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios
- 后端端口：9008，前端端口：5108，前端 `/api` 代理到 `http://localhost:9008`
- 数据库：`db_08_chronic`（utf8mb4）

## 角色与功能

### 患者（patient）
- 健康档案：查看/编辑个人基本信息、病种、风险等级，查看近期指标趋势
- 指标录入：录入收缩压/舒张压/空腹血糖/心率/体重，超阈值自动标记异常并生成预警
- 用药提醒：查看/新增/开启关闭/删除用药提醒
- 随访应答：查看医生制定的随访计划，填写应答提交

### 医生/护士（doctor）
- 随访计划制定：按病种/风险等级筛选患者，手动制定随访计划；**按模板自动生成**（创新点1）——遍历所有患者，按病种+风险等级匹配模板，按间隔天数自动生成随访计划
- 指标审核：对待审核指标进行通过/驳回，填写审核意见
- 异常预警处理：查看待处理预警，填写处理意见后标记已处理

### 管理员（admin）
- 患者分组：分组 CRUD，患者分配到分组
- 计划模板：随访计划模板 CRUD（病种+风险等级+间隔天数+随访内容）
- 统计报表：患者/医生数、异常指标数、待审核数、未处理预警数、待随访/已完成随访数、各分组患者分布

## 创新点

1. **随访计划自动生成**：医生点击"按模板自动生成随访计划"，后端遍历所有患者，按 `disease_type + risk_level` 匹配 `t_plan_template`，按 `interval_days` 推算计划日期，批量生成 PENDING 状态随访计划。
2. **异常指标预警**：患者提交指标时，后端自动按阈值判断（收缩压≥140、舒张压≥90、空腹血糖≥7.0或<3.9、心率>100或<60），超阈值自动标记 `status=ABNORMAL` 并写入 `t_warning` 预警记录，按数值大小分 HIGH/MID/LOW 三级。

## 修复的 Bug

1. **MyBatis 动态 SQL 语法错误**：IndicatorMapper / WarningMapper / FollowupPlanMapper 中 `<script>` 标签只包裹了动态片段，静态 SQL 在标签外，导致 `<if>` 被原样拼进 SQL 报 `SQLSyntaxErrorException`。修复方式：将整条 SELECT SQL 全部包进 `<script>...</script>`。

## 已知限制

- 登录态保存在前端 localStorage，后端无 session/token 鉴权（演示项目，接口未做登录拦截）。
- 随访计划自动生成按"今天 + interval_days"推算计划日期，未去重（重复点击会生成重复计划，演示用）。
- 用药提醒仅做列表管理，未接入定时推送。
- 指标测量时间为手动选择，未做服务端时间校验。
- 统计报表为数字卡片+分组分布表，未引入图表库。
