# 17 城市共享车位系统

车位发布、地图找位、预约、分时计费、订单管理，盘活闲时车位。
技术栈：SpringBoot 2.7.x + MyBatis + MySQL 8（JDK8） + Vue3 + Vite + Element Plus + Pinia。

## 系统功能

### 1. 平台管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **车位管理**：审核共享车位
- **用户管理**：管理车主和业主
- **订单管理**：查看所有停车订单
- **收费管理**：设置收费标准
- **信用管理**：管理信用积分
- **公告管理**：发布平台公告
- **数据统计**：平台运营数据

### 2. 业主（车位主）

注册、登录、个人信息、修改密码。

- **车位发布**：发布闲置车位
- **预约管理**：查看谁预约了
- **收益管理**：查看车位收益
- **提现**：申请提现

### 3. 车主（停车人）

注册、登录、个人信息、修改密码、查看系统公告。

- **找车位**：搜索附近车位
- **预约停车**：预约车位
- **导航寻车**：导航到车位
- **在线支付**：支付停车费
- **超时提醒**：收到超时提醒
- **信用评价**：评价车位
- **停车记录**：查看历史停车

## 功能清单

### 车主
- 地图找车位（SVG 区域示意图 + 车位卡片列表，可按区域筛选）
- 预约车位（查看车位详情 → 提交预约）

### 车位主
- 车位发布（填写车位信息提交，待管理员审核）

- 收益查看（累计收益 + 停车流水明细，按流水累计）

### 管理员
- 车位审核（通过 / 拒绝）
- 费率配置（高峰/非高峰单价、免费时长、阶梯折扣、平台抽成）
- 纠纷处理（查看纠纷 → 填写处理方案 → 标记解决）
- 数据统计（车位/订单/流水总额/用户数 + 各区域分布柱状图）

## 创新点实现

- **分时计价**：`FeeService.compute()` 先扣免费时长，再逐分钟按高峰时段(8:00-20:00)单价 8 元/小时、非高峰 5 元/小时计费；前 2 小时原价，超出部分按 0.8 折；最后按平台抽成 10% 拆分平台费与车位主收益。
- **停车流水**：每次结束停车自动生成 `t_park_record` 流水记录，车位主收益按流水累计求和。

## 实测修复的 Bug

1. **前端 store 导入路径错误**：6 个页面 `import from '../store'`（目录无 index.js），Vite 编译 500 白屏 → 改为显式 `../store/user`。
2. **后端时区偏移 8 小时**：JVM 默认 UTC，导致页面进场时间显示比实际早 8 小时 → `application.yml` 加 `spring.jackson.time-zone: Asia/Shanghai` 并在 `main()` 设置 `TimeZone.setDefault(Asia/Shanghai)`。
3. **退出登录后 Layout 渲染崩溃**：`user` 为 null 时 `user.role` 抛错导致页面卡死 → Layout 的 `user` computed 加空对象兜底、`roleText` 判空。

## 已知限制

- 「地图找车位」用 SVG 区域示意图 + 列表代替真实地图，非 GIS 坐标。
- 预约后进场/出场为手动点击按钮触发，无真实车牌识别/地磁检测。
- 金额计算按分钟粒度逐分钟累加，演示数据量下性能无影响。
