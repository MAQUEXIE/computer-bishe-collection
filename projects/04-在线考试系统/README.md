# 04 在线考试系统

题库 + 随机组卷 + 在线答题 + 自动阅卷 + 成绩分析,教学考全闭环。

- 后端: SpringBoot 2.7.18 + MyBatis + MySQL 8 (JDK8),端口 **9004**
- 前端: Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios,端口 **5104**
- 数据库: **db_04_exam** (utf8mb4),root/root
- 创新点: ① 智能随机组卷(按学科/题型/题量从题库随机抽题) ② 防切屏检测(visibilitychange/blur 累计警告,超限自动交卷)

## 系统功能

### 1. 管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **用户管理**：管理所有学生教师
- **题库管理**：录入单选题多选题判断题
- **科目管理**：管理考试科目
- **组卷管理**：设置试卷题目
- **考试管理**：安排考试时间
- **成绩管理**：查看所有成绩
- **统计分析**：通过率分析

### 2. 教师

登录、个人信息、修改密码。

- **题库管理**：维护本科目题目
- **试卷管理**：出试卷组卷
- **考试安排**：发布考试
- **成绩分析**：本科目成绩分析
- **错题统计**：常见错误分析

### 3. 学生

注册、登录、个人信息、修改密码、查看系统公告。

- **参加考试**：在线答题，倒计时
- **防切屏**：切屏自动交卷
- **成绩查询**：查看考试成绩
- **错题本**：查看做错的题
- **模拟考试**：考前模拟练习


浏览器打开 http://localhost:5104

## 实测中修复的 Bug

1. **ClassSubject.vue / Config.vue 缺少外层 `<template>` 块** — Vite 编译报 `Invalid end tag`,整页空白;已补全。
2. **智能组卷 500 错误 `Column 'total_score' cannot be null`** — 插入试卷时先把总分置 0,抽题完成后再 update_total_score 回填。
3. **阅卷页默认选中无数据试卷** — 改为自动选中考试记录最多的试卷,打开页面即有分析数据。

## 已知限制

- 自动阅卷覆盖单选/多选/判断(标准化题型),简答/作文类主观题未实现;教师批阅页仅查看,不支持手改分数。
- 密码为明文存储(教学演示用),生产环境需加密。
- 登录态仅存 localStorage,后端无会话;刷新页面不丢,清缓存需重新登录。
- 防切屏依赖 visibilitychange/blur,系统级截屏、多屏窗口拖动不计入警告。
