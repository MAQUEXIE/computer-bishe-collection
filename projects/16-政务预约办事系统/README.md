# 16 政务预约办事系统

办事事项、分时段预约、材料预审、排队叫号、办结评价，一网通办。

- **后端端口**：9016
- **前端端口**：5116（`/api` 代理到 http://localhost:9016）
- **数据库**：`db_16_gov`（utf8mb4）
- **技术栈**：SpringBoot 2.7.18 + MyBatis + MySQL 8（JDK8）；Vue3 + Vite + Element Plus + Pinia + Vue Router + Axios

---

## 系统功能

### 1. 政务管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **事项管理**：管理办事事项
- **窗口管理**：管理服务窗口
- **预约管理**：处理预约
- **材料管理**：设置材料要求
- **公告管理**：发布通知公告
- **评价管理**：查看窗口评价
- **数据统计**：办事数据统计

### 2. 窗口工作人员

登录、个人信息、修改密码。

- **预约列表**：查看当天预约
- **材料审核**：审核材料
- **办理登记**：登记办理结果
- **进度更新**：更新办事进度

### 3. 市民（办事人）

注册、登录、个人信息、修改密码、查看系统公告。

- **事项查询**：查询办事事项
- **办事指南**：看办事流程
- **在线预约**：预约办事时间
- **材料上传**：上传材料
- **进度查询**：查看办理进度
- **窗口评价**：评价窗口服务
- **办事记录**：查看历史办理

## 一键启动

### 1. 初始化数据库

```powershell
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4
```

（root/root，MySQL80 服务需运行中。）

### 2. 启动后端

```powershell
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'
mvn spring-boot:run
```

等待看到 `Started GovApplication`，端口 9016 监听。

### 3. 启动前端

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开 http://localhost:5116

## 角色与功能

- **市民**：事项查询、分时段预约、材料上传预审、排队叫号（每 3 秒轮询）、办结评价
- **窗口人员**：受理接件（叫号台）、材料审核（通过/驳回）、办结登记
- **管理员**：事项配置（增删改/启停用）、窗口排班（窗口管理 + 排班表）、效能统计

## 创新点

1. **预约 + 叫号联动**：市民预约"今日"时段后自动进入当日叫号队列（生成 A 号）；窗口人员叫号后，市民端排队页 3 秒内轮询刷新为"已呼叫，请前往 X 号窗口"。
2. **材料预审**：市民在"我的预约"中上传材料（本地文件选择，FileReader 读 base64，另提供"使用示例材料"按钮演示），窗口人员在材料审核页预审通过/驳回并填写意见，市民端实时看到状态与意见。

## 实测修复的 Bug

1. **效能统计"最近评价"市民/预约号空白**：MyBatis `List<Map>` 返回下划线键（citizen_name/appt_no），前端按驼峰取数。修复：SQL 中显式 `AS citizenName / AS apptNo` 别名。
2. **材料审核页 SQL 语法错误**：`<script>` 标签未包裹整条 SQL（只包了 WHERE 段），导致动态 SQL 被当字面量拼进 SQL。修复：整条 `<script>...</script>` 包裹。
3. **材料审核列表缺预约号/市民/事项**：联表列 `citizen_name` 无法映射到实体。修复：Material 实体增加 apptNo/citizenName/itemName 字段并 SQL 别名。

## 已知限制

- 排队叫号为后端轮询（3s）实现，未用 WebSocket；材料 base64 直接入库（演示用途，超长自动截断）。
- 演示数据中"今日"为 2026-10-24；当天队列数据见 init.sql，新预约若选今日会自动进队列。
- 图片资源均为项目内 SVG（public/images/logo.svg），无外链。
