# 11 食堂智慧结算系统（校园一卡通延伸）

餐补账户 + 档口收款 + 消费流水 + 营养分析。SpringBoot 2.7.x + MyBatis + MySQL 8 / Vue3 + Vite + Element Plus。

## 一键启动

```powershell
# 1. 初始化数据库（MySQL root/root）
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（端口 9011）
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'; mvn spring-boot:run

# 3. 启动前端（端口 5111，/api 代理到 9011）
cd frontend
npm install
npm run dev
```

浏览器打开 http://localhost:5111

## 端口与库名

- 后端：9011　前端：5111　数据库：`db_11_canteen`（utf8mb4）

## 创新点

1. **餐补自动充值**：`RechargeService.autoRecharge()` 每月 1 日 00:00（`@Scheduled`）自动为全体在籍师生各充 150 元餐补并写流水；按月份幂等（当月已发放则跳过）。管理员「餐补发放」页可手动点击「立即执行本月自动餐补发放」模拟月初发放。
2. **营养摄入统计**：每道菜配置热量/蛋白质/碳水/脂肪，收款时在消费流水里快照营养数据；师生端按天/按 7 天/30 天汇总热量、蛋白质、碳水、脂肪，含每日热量条形图与营养素结构进度条。

## 实测修复的 Bug

1. **时间列显示原始 ISO 字符串**（`2026-10-24T09:18:48.000+00:00`）→ 前端各表格统一加 `fmt()` 格式化为 `YYYY-MM-DD HH:mm:ss`。
2. **档口报表菜品排行「菜品」列空白**：MyBatis 返回 Map 时未对 `dish_name` 做驼峰映射 → SQL 显式别名 `dish_name AS dishName`，重启后端后正常。

## 已知限制

- 扫码消费为模拟实现（档口输入/选择卡号扣款），未接真实扫码硬件；消费码为按卡号生成的伪二维码点阵。
- 无服务端会话拦截，登录态存浏览器 localStorage，刷新页面不丢；后端重启不影响（不依赖 session）。
- 自动充值定时任务按 cron 每月 1 号执行，当月重复调用幂等跳过。
