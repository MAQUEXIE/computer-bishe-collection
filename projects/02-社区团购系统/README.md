# 02 社区团购系统

团长制生鲜团购：供应商供货、团长开团、居民参团自提，佣金自动结算。

## 系统功能

### 1. 平台管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **团长管理**：审核团长入驻，查看团长列表
- **商品管理**：管理团购商品，上下架商品
- **分类管理**：管理商品分类
- **订单管理**：查看所有订单，处理异常订单
- **自提点管理**：管理自提点信息
- **佣金规则**：设置佣金比例
- **公告管理**：发布平台公告
- **数据统计**：平台运营数据报表

### 2. 团长

注册、登录、个人信息、修改密码。

- **开团管理**：发起团购活动，设置开团时间
- **商品管理**：上架团购商品，设置价格库存
- **订单核销**：到店自提核销
- **佣金收益**：查看自己的佣金收益
- **团员管理**：管理小区团员
- **自提点**：管理自提位置

### 3. 团员（用户）

注册、登录、个人信息、修改密码、查看系统公告。

- **浏览团购**：浏览小区团购商品
- **参团购买**：下单拼团
- **订单管理**：查看订单
- **到店自提**：去自提点取货
- **评价晒单**：评价商品
- **分享邀请**：邀请好友得优惠券

## 技术栈
- 后端：SpringBoot 2.7.18 + MyBatis（注解 SQL）+ MySQL 8
- 前端：Vue 3 + Vite 4 + Element Plus + Vue Router + Pinia + Axios
- 端口：后端 9002，前端 5102（`/api` 代理到 `http://localhost:9002`）
- 数据库：`db_02_group_buy`（utf8mb4）

## 创新点实现
1. **拼团阶梯价**：每个团可配置多档阶梯价（满 N 件单价更低），居民参团时按 `当前已参件数 + 本次购买件数` 命中最优阶梯价；参团后实时刷新已参件数。
2. **佣金自动结算**：居民支付后若 `已参件数 >= 目标人数`，系统自动把该团状态置为 `completed`，并按 10% 费率为该团下所有已支付订单自动生成佣金流水（状态 `pending`）；管理员在「佣金结算」页面一键确认，转为 `settled` 并记录结算时间。

## 实测中修复的 Bug
1. **管理员 Stats 字段名错位**：前端用 `data.openGroup`，后端返回 `openGroupCount`，导致「进行中的团」显示 0 → 已修正字段名。
2. **Vue 模板语法错误**：批量使用了 `#default="{{ row }}"`（应为 `#default="{ row }"`）和 `{ { ... } }`（多空格），导致整个 admin 路由 chunk 加载失败、页面白屏 → 已批量修正全部 .vue 文件。
3. **LeaderController 字符串嵌套引号编译错误**：`"仅"已支付"订单可核销"` → 改为 `"仅已支付订单可核销"`。
4. **ResidentController/LeaderController 中 `body.get(...)` 返回 Object 直接赋值 String** → 显式强转。
5. **演示数据 after_sale 插入列错位**（reason 写到了 resident_id 列）→ 修正 INSERT 列与值对应关系。

## 已知限制
- 支付为前端模拟（点击「确认支付」直接调后端标记 paid），未接入真实支付网关。
- 登录态仅用 localStorage 存用户对象，未做 token 校验（教学演示项目）。
- 商品图片为内置 SVG 占位图（6 张，位于 `frontend/public/images/product/`），非真实摄影图。
- 团长若拒绝审核/售后后未做复杂状态回滚（仅更新状态）。
