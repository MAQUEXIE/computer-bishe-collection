# 27 固定资产管理系统

资产全生命周期管理：登记 → 申领/借用 → 调拨 → 报修 → 处置全链路留痕；每件资产生成唯一编号 + 二维码标签，扫码即可查看资产详情与生命周期轨迹。

## 技术栈

- 后端：SpringBoot 2.7.18 + MyBatis（注解 SQL）+ MySQL 8，JDK 1.8
- 前端：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios + qrcode
- 后端端口 **9027**，前端端口 **5127**，前端 `/api` 代理到 `http://localhost:9027`
- 数据库：**db_27_asset**（utf8mb4），root/root

## 一键启动

```powershell
# 1. 建库（PowerShell 不支持 < 重定向，用管道）
cd D:\000-计算机项目\30个系统项目\27-固定资产管理系统
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（Maven 必须用 JDK8）
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'; mvn spring-boot:run

# 3. 启动前端（另开终端）
cd frontend
npm install
npm run dev

# 浏览器打开 http://localhost:5127
```

## 功能与创新点

- **员工**：资产领用中心（申领/借用/二维码标签查看）、我的申请（借用归还）、我要报修、我的盘点（账实相符/差异登记）
- **资产管理员**：资产登记（自动生成编号 ZC-2026-XXXX + 二维码标签）、资产台账（二维码标签预览、生命周期抽屉）、资产调拨、处置申请、报修受理/完成、盘点管理（创建批次自动盘入全部资产、明细核对、结束盘点）
- **领导/管理员**：资产报表（状态分布/分类统计/预算执行/收支汇总）、预算管理（年度预算 + 收支流水登记）、审批中心（申领/借用审批 + 处置审批）
- **创新点 1 二维码标签**：`qrcode` 库前端实时渲染 PNG 二维码（内容即资产编号），登记成功页、台账、员工列表均可展示；`/scan?no=编号` 页面可输入编号模拟扫码查看详情
- **创新点 2 全生命周期留痕**：每次登记/申领/借用/归还/调拨/报修/维修完成/处置都写 `t_log`，扫码详情页与台账抽屉以时间线完整展示

## 修复的 bug

实测过程中未发现产品级 bug；以下为环境/操作层面的记录：
1. Element Plus 下拉在浏览器自动化中需用 JS 触发展开（`document.querySelector('.el-select__wrapper').click()`），普通 ref 点击偶发被遮罩拦截——已在全局样式禁用过渡动画规避动画卡死问题。
2. 自动化脚本中连续点击两个"明细核对"按钮会因两个异步请求竞态出现弹窗标题与数据短暂不一致——已改为单按钮操作规避；真实用户单次点击无此问题。

## 已知限制

1. 无摄像头扫码硬件，"扫码"以前端输入资产编号跳转 `/scan?no=xxx` 模拟；二维码本身是真实可扫的 PNG（内容=资产编号）。
2. 同一资产被两人先后申领并都审批通过时，后通过者覆盖使用人（演示数据现象，生产中应加并发校验）。
3. 登录态保存在浏览器 localStorage，后端无 session 拦截，刷新后重登即可。
