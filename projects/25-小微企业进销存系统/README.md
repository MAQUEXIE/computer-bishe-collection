# 25-小微企业进销存系统

商品、采购、销售、库存预警、利润报表，生意一本账。SpringBoot 2.7 + MyBatis + MySQL 8 + Vue3 + Vite + Element Plus。

## 系统功能

### 1. 老板/管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **商品管理**：管理所有商品
- **客户管理**：管理客户
- **供应商管理**：管理供应商
- **采购管理**：看采购单
- **销售管理**：看销售单
- **库存管理**：看库存
- **财务统计**：利润统计
- **报表导出**：导出Excel报表

### 2. 采购员

登录、个人信息、修改密码。

- **采购申请**：提采购申请
- **采购单管理**：管理采购单
- **供应商管理**：维护供应商
- **入库**：验收入库

### 3. 销售员

登录、个人信息、修改密码。

- **客户管理**：维护客户
- **销售单**：开销售单
- **出库**：处理出库
- **回款**：登记回款

### 4. 仓库管理员

登录、个人信息、修改密码。

- **入库**：处理入库
- **出库**：处理出库
- **库存盘点**：盘点库存
- **库存预警**：查看预警

## 一键启动

### 1. 初始化数据库
```powershell
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4
```

### 2. 启动后端
```powershell
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'
mvn spring-boot:run
```

### 3. 启动前端
```powershell
cd frontend
npm install
npm run dev
```
浏览器打开 http://localhost:5125

## 实测中修复的 Bug

1. **销售/采购明细插入报 `Parameter 'saleId'/'purchaseId' not found`**：MyBatis `<foreach>` 批量插入时引用了外层 `#{saleId}`/`#{purchaseId}`，但 Mapper 方法只声明了 `@Param("items")`。修复：方法签名改为 `insertItems(@Param("saleId") Long saleId, @Param("items") List<...>)`，Controller 调用时传入单据主键。
2. **系统设置页报 `Unknown column 'lt' in where clause`**：`ProductMapper.lowStockList()` 是注解裸 SQL（非 `<script>` 包裹），`&lt;=` HTML 实体不会被解码，原样下发 MySQL 报错。修复：注解裸 SQL 中直接写原生 `<=`（仅 `<script>` 包裹的动态 SQL 才需要 `&lt;`/`&gt;` 实体转义）。

## 创新点

- **库存预警**：库存 ≤ 安全库存时，库存查询页顶部红色横幅告警 + 整行标红 + 自动给出「补货至安全库存 2 倍」的建议数量；管理员系统设置页同步展示预警商品数。
- **利润分析**：销售单落库时按 `售价-成本价` 实时核算每单毛利与毛利率；老板页可按商品（毛利排名+利润率条）和按时段（销售报表日汇总）两个维度查看。
