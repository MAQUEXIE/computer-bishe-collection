# 22-校园社团管理系统

社团全周期管理：社团入驻审核、成员管理、活动报名、经费全流程（申请→审批→拨付→支出登记→余额台账），并按活跃度自动进行社团星级评定。

- **后端**：SpringBoot 2.7.18 + MyBatis + MySQL 8（JDK 8），端口 **9022**
- **前端**：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios，端口 **5122**（/api 代理到 9022）
- **数据库**：`db_22_club`（utf8mb4）

## 系统功能

### 1. 管理员（团委）

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **社团管理**：管理系统的社团信息
- **审批管理**：管理所有学生的社团申请审批信息
- **成员管理**：管理所有社团的成员信息
- **活动管理**：管理所有社团的活动信息
- **资讯管理**：管理所有社团的资讯信息
- **评论管理**：管理所有社团的评论信息
- **公告管理**：管理系统公告信息
- **管理员信息**：管理系统管理员的相关信息
- **学生信息**：管理系统学生的信息

### 2. 社长

注册、登录、个人信息、修改密码。

- **社团管理**：管理自己的社团
- **申请审批**：对申请自己社团的学生进行审核审批
- **社团成员**：查看自己社团的成员
- **社团活动**：管理自己社团的活动
- **社团资讯**：管理自己社团的资讯
- **评论管理**：管理自己社团的评论

### 3. 普通学生

注册、登录、个人信息、修改密码、查看系统公告。

- **查看社团资讯**：可以查看各种社团的资讯
- **查看社团活动**：可以查看各种社团的活动
- **查看社团信息**：可以查看各种社团的信息
- **社团申请**：可以向自己感兴趣的社团申请加入
- **我申请的社团**：可以查看自己的所有申请记录

## 一键启动

```powershell
# 1. 初始化数据库（MySQL CLI 不在 PATH，用全路径）
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（Maven 默认 JDK21，必须切 JDK8）
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'
mvn spring-boot:run

# 3. 启动前端（新终端）
cd frontend
npm install
npm run dev
# 打开 http://localhost:5122
```

## 实测中修复的 Bug

1. **MyBatis 动态 SQL 未生效**：`<script>` 标签必须包裹整条 SQL，初版把 `<script>` 写在 JOIN 之后导致 `<if>` 条件被当文本拼接、club/list 报 500。已修复 ClubMapper/ExpenseMapper/DuesMapper，全部动态 SQL 改为整条包裹。
2. **发布活动 500**：活动时间传空串 `""` 时 `LocalDateTime.parse("")` 抛异常导致弹窗提交无反应。后端改为空串跳过解析。
3. **退出登录后 Layout 渲染崩溃**（`store.user` 为 null 读 nickname）：Layout 顶栏加 `v-if` 守卫。

## 创新点

- **社团星级自动评定**：评分 = 成员数 + 已通过活动数×3 + 活动报名人次，≥25→5星、≥15→4星、≥8→3星、≥3→2星、其余1星；团委可在数据统计页一键重算，星级榜按星级排序。
- **经费全流程闭环**：社长申请 → 团委审批（通过自动拨付余额）→ 社长支出登记（余额校验扣减）→ 台账展示（余额/累计获批/累计支出），社费缴纳也自动计入社团余额。
