# 15-社区活动管理平台

活动发布、在线报名、扫码签到、积分体系、活动相册，社区运营工具。

## 系统功能

### 1. 社区管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **活动管理**：发布审核活动
- **志愿者管理**：管理志愿者
- **报名管理**：查看报名名单
- **签到管理**：活动签到
- **积分管理**：设置积分规则
- **公告管理**：发布社区公告
- **数据统计**：活动参与统计

### 2. 居民

注册、登录、个人信息、修改密码、查看系统公告。

- **活动浏览**：浏览社区活动
- **在线报名**：报名参加活动
- **签到打卡**：活动签到
- **志愿者**：报名当志愿者
- **活动相册**：查看活动照片
- **积分兑换**：用积分换礼品
- **我的活动**：查看参加的活动

## 技术栈

- 后端：SpringBoot 2.7.18 + MyBatis(2.3.2) + MySQL 8（JDK8），端口 **9015**
- 前端：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios，端口 **5115**（/api 代理到 9015）
- 数据库：**db_15_community**（utf8mb4）

## 一键启动

```powershell
# 1. 初始化数据库（首次）
Get-Content db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（注意必须先切 JDK8）
cd backend
$env:JAVA_HOME='C:\Program Files\Amazon Corretto\jdk1.8.0_492'; mvn spring-boot:run

# 3. 启动前端（新终端）
cd frontend
npm install
npm run dev
```

浏览器打开 http://localhost:5115

## 创新点：报名+签到核销闭环 + 积分体系

居民在线报名 → 系统生成个人 6 位签到核销码 → 居民在「我的报名」出示该码 → 组织者在「签到核销」输入码核销 → 报名/签到/上传相册三类行为按可配置积分规则自动加分并写积分流水（`t_point_log`）。

## 修复的 Bug（实测发现）

1. **活动发布提交 500**：Jackson 无法把 `yyyy-MM-dd HH:mm:ss` 反序列化为 Date → Activity 实体 startTime/endTime 加 `@JsonFormat`。
2. **列表时间列显示原始 ISO 串**：前端新增 `src/utils.js` 的 `fmt()`，各表格/时间线统一格式化。
3. **审核页操作列被窄视口裁掉**：精简表格列（去掉地点/提交时间）。

## 已知限制

- 无登录拦截器（按项目 03 验证模式，前端 Pinia 存用户，接口传 userId）。
- 签到为「组织者输入居民出示的核销码」模拟扫码，未接摄像头/二维码生成。
- 相册上传支持本地图片（base64）与项目内置 SVG 图选择二选一。
- 取消报名不回退已发放积分。
