# 21 供应链采购系统

采购全流程：需求汇总 → 询价比价 → 生成采购单 → 发货跟踪 → 到货验收 → 入库登记 → 付款对账，四角色协同。

- **后端端口**：9021　**前端端口**：5121　**数据库**：`db_21_supply`（utf8mb4）
- **技术栈**：SpringBoot 2.7.18 + MyBatis + MySQL 8（JDK8）；Vue3 + Vite + Element Plus + Pinia + Axios

## 系统功能

### 1. 系统管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **供应商管理**：审核供应商
- **物料管理**：管理物料分类
- **采购管理**：管理采购流程
- **仓库管理**：管理仓库
- **财务管理**：对账结算
- **用户管理**：管理各角色账号
- **数据统计**：供应链数据报表

### 2. 采购人员

登录、个人信息、修改密码。

- **供应商选择**：选供应商
- **采购申请**：提采购申请
- **订单管理**：下采购订单
- **到货跟进**：跟到货
- **对账**：和供应商对账

### 3. 仓库管理员

登录、个人信息、修改密码。

- **入库验收**：验收入库
- **库存管理**：查看库存
- **出库管理**：处理出库
- **库存预警**：处理低库存预警
- **盘点**：库存盘点

### 4. 财务人员

登录、个人信息、修改密码。

- **对账**：核对账单
- **付款管理**：安排付款
- **发票管理**：管理发票
- **结算报表**：财务结算报表

## 创新点实现

1. **比价自动化**：发起询价后，系统按「综合性价比 = 报价 × 评分系数」自动排序，评分 60 分=系数 1.00，每高 1 分优惠 0.2%（最高约 8% 权重），自动标记「推荐最优」。实测 XD2026002 纸箱需求：恒信 ¥3.25×0.95=¥3.09 被推荐。
2. **供应商评价**：仓库到货验收时填写价格/质量/交期三维评分，系统自动回算供应商平均分并计入后续比价权重。实测华原钢铁验收后综合评分由 86.2 → 89.2，报表排行实时更新。

## 已知限制

- 登录态存前端 localStorage，后端无会话拦截（与项目 03 脚手架一致），演示环境适用。
- 到货验收与入库登记为两步独立操作；数量不支持部分到货多次验收（每次验收生成一条 receipt，订单只取第一次验收结果流转状态）。
- 供应商注册后价格库为空，需管理员在「价格库」中补录报价后才会被自动询价纳入。
