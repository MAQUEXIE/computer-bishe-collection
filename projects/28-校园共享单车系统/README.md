# 28 校园共享单车系统

校内出行服务：学生扫码用车、骑行计费、故障报修；调度管理员/调度员进行车辆管理、潮汐调度、运维处理与数据看板。

## 系统功能

### 1. 管理员

登录、个人信息、修改密码、管理后台管理系统所有数据。

- **车辆管理**：管理所有单车
- **区域管理**：设置停车区域
- **订单管理**：查看所有骑行订单
- **故障管理**：处理故障上报
- **收费管理**：设置收费标准
- **信用管理**：管理信用积分
- **数据统计**：骑行数据报表

### 2. 学生用户

注册、登录、个人信息、修改密码、查看系统公告。

- **找车**：看附近单车位置
- **扫码开锁**：扫码骑车
- **骑行记录**：查看骑行历史
- **计费支付**：支付骑行费
- **故障上报**：上报故障单车
- **信用积分**：查看自己的积分
- **停车**：停到指定区域

## 技术栈
- 后端：FastAPI + SQLAlchemy 2.0 + PyMySQL + Pydantic（端口 **9028**）
- 前端：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios（端口 **5128**，/api 代理到 9028）
- 数据库：MySQL `db_28_bike`（utf8mb4）

## 一键启动

```powershell
# 1. 导入数据库（MySQL root/root）
Get-Content D:\000-计算机项目\30个系统项目\28-校园共享单车系统\db\init.sql -Raw -Encoding UTF8 | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' --user=root --password=root --default-character-set=utf8mb4

# 2. 启动后端（目录 backend）
cd D:\000-计算机项目\30个系统项目\28-校园共享单车系统\backend
python -m uvicorn main:app --host 0.0.0.0 --port 9028

# 3. 启动前端（新窗口，目录 frontend）
cd D:\000-计算机项目\30个系统项目\28-校园共享单车系统\frontend
npm install   # 首次
npm run dev
```
浏览器打开 http://localhost:5128

- **学生**：扫码用车（输入单车二维码编号模拟扫码）、骑行结束、费用结算（起步价1.5元含15分钟，超出0.1元/分钟）、故障报修、我的行程、信用积分查询。

## 修复的 bug
1. `student/Scan.vue` 导入路径写错一级（`../api` → `../../api`、`../store/user` → `../../store/user`），导致 Vite 编译失败白屏，已修复。

## 已知限制
- 「扫码用车」为单车二维码编号输入模拟，未接真实扫码摄像头。
- 定位经纬度为演示坐标，未接真实地图。
- 结算时长为按开锁到结束的真实 elapsed 分钟（最少计 1 分钟）。
- token 存内存，重启后端需重新登录。
