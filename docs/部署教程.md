# 通用部署教程

> 所有项目通用的部署步骤，跟着做就行

---

## 一、环境准备

### 1. JDK（Java开发环境）

**下载**：
- JDK 8 或 JDK 11
- 官网：https://www.oracle.com/java/technologies/downloads/

**配置环境变量**：
```
JAVA_HOME = C:\Program Files\Java\jdk1.8.0_xxx
PATH = %JAVA_HOME%\bin;
```

**验证**：
```bash
java -version
# 显示版本号即成功
```

---

### 2. Maven（项目构建工具）

**下载**：
- Maven 3.6+
- 官网：https://maven.apache.org/download.cgi

**配置环境变量**：
```
MAVEN_HOME = C:\apache-maven-3.6.x
PATH = %MAVEN_HOME%\bin;
```

**验证**：
```bash
mvn -version
```

---

### 3. Node.js（前端运行环境）

**下载**：
- Node.js 16.x 或 18.x（LTS版本）
- 官网：https://nodejs.org/

**验证**：
```bash
node -v
npm -v
```

---

### 4. MySQL（数据库）

**下载**：
- MySQL 8.0
- 官网：https://dev.mysql.com/downloads/mysql/

**安装注意**：
- 设置root密码
- 字符集选 utf8mb4
- 端口默认3306

**验证**：
```bash
mysql -u root -p
# 输入密码能登录即成功
```

---

## 二、启动后端

### 1. 导入数据库

```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE xxx_db CHARACTER SET utf8mb4;

# 使用数据库
USE xxx_db;

# 导入SQL脚本
source D:/path/to/sql/xxx.sql;
```

### 2. 修改配置

打开 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/xxx_db?useUnicode=true&characterEncoding=utf8&serverTimezone=GMT%2B8
    username: root
    password: 你的数据库密码
```

### 3. 启动后端

```bash
cd backend

# 方式一：用IDEA启动
# 找到 XxxApplication.java，右键 Run

# 方式二：命令行启动
mvn spring-boot:run
```

**验证**：
- 控制台显示 "Started XxxApplication in x.xxx seconds"
- 访问 http://localhost:8080 能看到接口文档

---

## 三、启动前端

### 1. 安装依赖

```bash
cd frontend

npm install
# 如果下载慢，用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### 2. 启动开发服务器

```bash
npm run dev
```

**验证**：
- 浏览器打开 http://localhost:5173
- 能看到登录页面即成功

## 四、常见问题

### Q1：npm install 很慢/失败
**解决**：换淘宝镜像
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q2：后端启动报数据库连接错误
**解决**：
1. 检查MySQL是否启动
2. 检查application.yml中的用户名密码
3. 检查数据库是否创建了

### Q3：前端页面空白/报错
**解决**：
1. 按F12打开控制台，看报什么错
2. 检查后端是否启动了
3. 检查前端的API地址配置（vite.config.js中的proxy）

### Q4：端口被占用
**解决**：
- 后端：修改application.yml中的server.port
- 前端：修改vite.config.js中的port

## 五、打包部署（可选）

### 后端打包
```bash
cd backend
mvn clean package -DskipTests
# 生成 target/xxx.jar
```

### 前端打包
```bash
cd frontend
npm run build
# 生成 dist/ 目录
```
