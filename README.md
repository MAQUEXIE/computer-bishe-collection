## 🚀 快速开始

每个项目都有详细的部署教程，通用步骤如下：

```bash
# 1. 导入数据库脚本
mysql -u root -p < db/init.sql

# 2. 启动后端
cd backend
mvn spring-boot:run

# 3. 启动前端
cd frontend
npm install
npm run dev
```

详细教程请查看每个项目目录下的 README.md。
