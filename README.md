## 🚀 快速开始

每个项目都有详细的部署教程，通用步骤如下：

```bash
# 1. 导入数据库脚本
mysql -u root -p < sql/xxx.sql

# 2. 启动后端
cd backend
mvn spring-boot:run

# 3. 启动前端
cd frontend
npm install
npm run dev
```

详细教程请查看每个项目目录下的 README.md。

## 🛠️ 技术栈说明

### 后端技术
- **框架**：SpringBoot 2.x / 3.x
- **ORM**：MyBatis / MyBatis-Plus
- **数据库**：MySQL 8.0
- **缓存**：Redis（部分项目）
- **安全**：Spring Security / JWT

### 前端技术
- **框架**：Vue 3
- **构建工具**：Vite
- **UI组件**：Element Plus
- **HTTP库**：Axios
- **状态管理**：Pinia
